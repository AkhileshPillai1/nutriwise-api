Hello. This is NutriWise's API codebase written using express an typescript.

### Getting started:

`npm i` : To install all dependencies  
`npm run dev` : To start a local development server with hot reload  
`npm run build` :  To create an optimized production build (Yet to implement)

### Git setup:

To get started, create your own fork and clone it in your system. Make sure to enable fork syncing.  
After doing any changes, commit and push to your fork and create a pull request against the original repository.

The `dev` branch is for development and points to the DEV environment. Build new features and test them on dev environment.  
The `prod` branch points to the PROD enviroment. Once code is tested on dev, you can cherry-pick changes to PROD branch.
